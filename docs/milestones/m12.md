## Drafting rationale — 2026-09-23

**Numbering and order ruled by Marius, 2026-09-23: *"Run before row 9. It's top priority."*** The row is
numbered 12 and appended, and nothing is renumbered, which is the precedent row 11 set. Its place in the
order is carried by its Status cell and by the Sequencing rationale, not by its number: row 9 multiplies
fresh contexts, and each one pays the always tier again, so the tier is priced first.

**The sessions column reads *1 per change*, not a total.** Proposal 0036 orders nine changes, one per pull
request. The last is a proposal of its own, and how many demotions Portulan's own footprint needs is set by
what the measurement finds, so a total written today would be a guess.

**Three demonstrations, each chosen to prove a different thing is real:**

- **A declared budget forced over is red, and a demotion returns it green.** The rail exists, and its
  remedy is the one the rule names. A raise in the same change is barred by doctrine, as it is for memory,
  and no checker establishes that one did not happen: [`../../spec/slots.md`](../../spec/slots.md) records
  the same limit for memory's budgets.
- **An on-path target loads when its path is first touched, and not before.** A compiled file at a path a
  human knows is not a tier. Row 7's parity clause learned this about skills: a count that reproduces from
  a directory with no workspace in it demonstrates nothing.
- **Portulan's own footprint and the demo workspace's boot read-set, measured before and after, the smaller
  figures arriving on upgrade.** That is the goal's clause *by installing or upgrading*, and the only one
  of the three an adopter would notice without reading a report.

**What the row leaves out, on purpose:**

- **The handoff series' size budget.** Ruled its own proposal, `0037`. Handoffs are an on-read cost, not an
  always-tier one, and a budget on the series total has every remedy barred.
- **The adoption in the sealed repository.** It is private, and a milestone's exit criterion must be
  demonstrable from this repository alone
  ([`a-public-criterion-must-be-demonstrable-from-this-repo`](../../.portulan/memory/a-public-criterion-must-be-demonstrable-from-this-repo.md)).
  It gates nothing here.
- **A version number.** The manifest key needs a MINOR, and `2.9` is commissioned by
  [`0034`](../../.portulan/proposals/0034-one-spec-bump-carries-both-evals-and-telemetry.md) and not yet
  drafted. The row names no version, so it cannot pre-empt that choice. _(Settled when the key was drafted:
  it took `2.9` alone in [#440](https://github.com/sleepy-panda-srl/portulan/pull/440), since `0034`'s
  accepted text commissions one MINOR without naming its number; `0034`'s slots and `0038`'s keys take the
  next free MINOR.)_
