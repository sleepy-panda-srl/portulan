## Drafting rationale — 2026-10-30

**Commissioned by Marius Cetanas (`2026-10-27` – `2026-10-30`)** after live benchmarking of two local 8-bit
MLX models (`qwen/qwen3.8-27b` and `google/gemma-4-31b`) and `text-embedding-nomic-embed-text-v1.5` on
LM Studio against Portulan's own [`../../cli/comments.mjs`](../../cli/comments.mjs),
[`../../cli/doctor.mjs`](../../cli/doctor.mjs), and
[`../../cli/skill-goldens.mjs`](../../cli/skill-goldens.mjs) predicates:

- **Pack residence settled in `sleepy-panda-srl/portulan` (`packs/tools/local-llm/`).** The runner uses only
  Node.js built-ins (`fetch`, `node:child_process`) and its verify recipe (`--verify-offline`) makes zero
  network calls, obeying the standing prohibition on network I/O inside verify recipes.
- **Role evaluation settled as Option A (`local-llm.mjs eval`).** `cli/ab-run.mjs` stays pure for host-level
  CLI agents, while `packs/tools/local-llm/runner/local-llm.mjs` exposes an `eval` subcommand that imports
  Portulan's own grading predicates to test any local model on `code`, `codify`, and `handoff` workloads.
- **Sequencing:** Row 14 extends rows 12 ([`m12.md`](m12.md)) and 13 ([`m13.md`](m13.md)) to zero-floor local
  loopback execution (`omitClaudeMd`, input-byte ceiling, explicit thinking effort cap, verify-gated
  rollback, and ledger accounting for local turns offloaded from the parent context). Remaining work is
  tracked on GitHub under milestone [`M14 · Hybrid local economy`](https://github.com/sleepy-panda-srl/portulan/milestone/16):
  [#541](https://github.com/sleepy-panda-srl/portulan/issues/541),

## Ruled before close — 2026-10-30

Found reviewing [#546](https://github.com/sleepy-panda-srl/portulan/pull/546), each one the criterion's
wording or its bar, and ruled by the maintainer the same day. The reasons are in `0039`'s *What was ruled*.

- **Row 14, clause 3 of `0039` and the sequencing note above said "atomic rollback".** The runner gives
  rollback, not atomicity: a verify command needs the edited file in place, so any other signal that ends
  the runner, SIGKILL among them, or a power loss between the edit and its verdict leaves the edit, as
  [`../../packs/tools/local-llm/README.md`](../../packs/tools/local-llm/README.md) states. **Ruled:** all
  three say rollback and state the limit, and no atomicity is built (`0039` ruling 4).
- **Clause 4 said routing is earned through `local-llm.mjs eval`, matching `0038` Rule 4.** `eval` takes
  one sample per task with no baseline arm, which is a screen rather than the A/B run Rule 4 requires.
  **Ruled** (`0039` ruling 5): the record is [#547](https://github.com/sleepy-panda-srl/portulan/issues/547).
- **The row named no demonstrations**, so milestone-close had nothing to re-derive. **Ruled:** it names
  four (`0039` ruling 3). `runner-rails` and `cli/pack-local-llm.test.mjs` carry the first two from #546;
  the ledger and `compile` demonstration falls to
  [#543](https://github.com/sleepy-panda-srl/portulan/issues/543) and
  [#544](https://github.com/sleepy-panda-srl/portulan/issues/544), and the routing record to #547.
- **[#545](https://github.com/sleepy-panda-srl/portulan/issues/545)'s `dedup` subcommand sat outside the
  row.** **Ruled:** it joins the row rather than leaving the milestone, so the criterion now names it.
