## Drafting rationale as it stood in the row

**This row is drafted so that a compliant v1 is _possible_; it does not assert that the constitution permits one** — a chat application runs an agent loop and takes turn-level actions, which makes it a **host** rather than one more renderer over the files, and `vision.md` has not ruled on that category. **Numbering ruled by Marius, 2026-07-27: milestone 10 keeps its number; this is 11 and nothing is renumbered.** The two live answers to Q2 build different products: **Q2(b)** — a workspace surface with no chat and no loop — is the far smaller build and asks for no new permission, only the maintainer's confirmation of the *fleet versus one workspace* reading that Q1 puts to him; **Q2(a)**, the bundled reference host, additionally needs redlines A and B drafted in that proposal to land in `vision.md` **in the maintainer's own hand** first. The sessions estimate covers Q2(a) and should be read as a floor.
