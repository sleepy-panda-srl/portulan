# packs/rituals/

Ritual packs — repeatable procedures that compose onto the loop: PR babysitting, bot-review
reconciliation, release runbooks, the codify/librarian pass.

| Pack | What it carries |
|---|---|
| [`checkpoints`](checkpoints/README.md) | The supervised-build ritual: three checkpoints graded by a fresh context, a `supervisor` persona, and the verdict vocabulary. Milestone 6. |
