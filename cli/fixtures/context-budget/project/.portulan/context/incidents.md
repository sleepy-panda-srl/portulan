# Borrowing incidents

Use this procedure when a patron reports that an item was checked out twice,
returned without clearing a loan, or reserved for the wrong borrowing account.
Ordinary catalog changes do not need these incident details.

1. Record the item identifier and the operation the patron expected. Keep the
   original borrowing entry available while investigating; correcting an entry
   before understanding it removes the evidence for the review.
2. Read the item's current availability and its latest loan together. A catalog
   display alone cannot establish whether the borrowing transaction succeeded.
   Note any difference between the display and the borrowing record.
3. Check whether the operation was retried. A second request can describe the
   same borrowing attempt rather than a second loan. Compare the recorded
   operation identifiers before proposing to remove either entry.
4. Inspect reservations separately from active loans. A reservation promises a
   future turn and does not prove possession of the item. Preserve its queue
   position until the review establishes which account should hold it.
5. Prepare the smallest correction that reconciles the records. Explain which
   observation supports it, retain the previous values, and ask the reviewer
   to decide whether the proposed correction matches the incident.
6. After the correction is approved and applied, read availability, loans and
   reservations again. Record the observed result and any question that remains
   open so the next librarian can continue without reconstructing the incident.
