- **[`cli/ledger.mjs`](../cli/ledger.mjs) reports the local runner's receipts apart from the host's tokens.**
  A receipt counts only as a whole line in the runner's receipt format, in the result of a Bash call the same transcript made, so an agent's report, a prompt or an assistant's text quoting one is not a second receipt, and a figure the server did not report stays unreported rather than 0. A format is all the ledger can check: any Bash output with a matching line is counted, a `cat` or `grep` over a log or a model's `chat` or `summarize` text echoing one among them, and a receipt the host did not record inline is missed, which may happen to one in a result too large for the transcript and kept as a preview, or one read back through a background task's output. The report prints them on their own line at `$0.00`, beside the host's token rows, and the restart threshold stays the host's alone and finite. The new hybrid-session fixture, [`cli/fixtures/ledger-hybrid/`](../cli/fixtures/ledger-hybrid/), demonstrates it in the `ledger` recipe, for row 14 of [`docs/plan.md`](../docs/plan.md).
