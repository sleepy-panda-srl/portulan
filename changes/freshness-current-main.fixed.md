- **The branch freshness check compares against the live `main` ref.** A PR's stored `base.sha` can lag the base branch: #555 retained an older SHA after `main` advanced, and the check reported zero behind while the live comparison was three. The check now reads `branches/main` before comparing and again before publishing, retries live ref movement even when the PR payload is unchanged, and refuses missing or malformed live-ref data. Regression cases hold the ten/eleven boundary against a stale PR payload.
