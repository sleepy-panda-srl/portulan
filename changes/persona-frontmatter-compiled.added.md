- **A persona can declare what its context costs, and `compile` writes it into the persona's agent binding.**
  `model`, `effort`, `omitClaudeMd` and `cacheLifetime` are optional persona fields, failed by `doctor` and refused by `compile` when malformed and never defaulted; for a persona a composed pack ships, `compile` writes the declared fields into its hand-written binding at `agents/<name>.md`, byte-compared under `--check`, and prints a degradation line for each field a host cannot express. Claude Code loads `agents/` only from a plugin root, and `compile` does not write `.claude/agents/`, so outside a plugin the compiled fields are loaded by nothing, which the degradation report states. The `local-worker` persona of `tools/local-llm` declares `omitClaudeMd: true` and `effort: low`, held to a committed golden in [`../cli/compile.test.mjs`](../cli/compile.test.mjs). See [`../core/personas/README.md`](../core/personas/README.md).
