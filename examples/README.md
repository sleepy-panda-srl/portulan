# examples/

A fictional, **public** demo workspace — the reference a stranger reads to see a real Portulan setup
end to end, with no private content. It will be one of the two workspaces `doctor` validates (the other
being [`../.portulan/`](../.portulan/), this repository's own), and what the quickstart walks through.

It also serves a purpose the reader does not see: it is the Workspace Definition's **second** instance,
and a schema derived from one sample is not tested until it meets a differently-shaped one. It is
deliberately given more than one product, because [`../spec/`](../spec/) claims to be portfolio-aware and
customer zero cannot demonstrate that.
